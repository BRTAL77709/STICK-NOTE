# SECTION 31 — PREDICT FAILURES BEFORE THEY HAPPEN

Before rendering, identify likely failure points.

## Character appears to run in place

Possible cause:
Missing root displacement.

Repair:
Synchronize root motion with stride length and cadence.

## Feet slide

Possible cause:
Incorrect stance constraints or inconsistent root velocity.

Repair:
Use stable world-space foot targets during stance.

## Hands float away from objects

Possible cause:
Incorrect parenting or constraint blending.

Repair:
Preserve world transforms and use stable grip targets.

## Door rotates incorrectly

Possible cause:
Pivot at center rather than hinge.

Repair:
Move pivot to hinge and validate swept volume.

## Car interior does not match exterior

Possible cause:
Disconnected vehicle models.

Repair:
Use one master vehicle with coherent dimensions.

## Mirror shows wrong view

Possible cause:
Incorrect reflection camera orientation.

Repair:
Align mirror view to actual rearward scene.

## Camera sees through wall

Possible cause:
Camera path intersects opaque geometry.

Repair:
Reposition camera inside valid free space.

## Curtain looks rigid

Possible cause:
Missing deformation.

Repair:
Use appropriate fabric rig or cloth behavior.

## Character does not climb stairs

Possible cause:
Flat-ground cycle and missing vertical root motion.

Repair:
Use actual tread targets and ascending pelvis trajectory.

## Phone floats

Possible cause:
Broken grip constraint.

Repair:
Attach phone to hand during grip and preserve transforms.

## Objects teleport between shots

Possible cause:
Inconsistent world origins or scene coordinates.

Repair:
Use shared transforms and continuity validation.

## Video flickers

Possible cause:
Lighting, geometry, or rendering instability.

Repair:
Identify source through frame comparisons and render diagnostics.

## MP4 is valid but animation is poor

Possible cause:
Validation checked only file metadata.

Repair:
Inspect actual moving footage and character actions.
