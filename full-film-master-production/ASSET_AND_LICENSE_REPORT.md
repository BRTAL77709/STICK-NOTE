# Assets, licenses and tool evaluation

Approved characters, V10 choreography and existing illustrated designs are user-provided/project assets, reconstructed under the user's explicit authorization. No external film frames or reference audio are copied into this production. New vectors, procedural sound effects and tonal score are authored in this project.

Local fonts: DejaVu Sans, with the supplied font copyright/license notice in hyperframes/assets/FONT_LICENSE.txt. GSAP 3.15.0 retains its copyright header and standard license (https://gsap.com/standard-license/). HyperFrames 0.8.226 is Apache 2.0. Existing Kokoro model is Apache 2.0; kokoro-onnx is MIT, with notices under assets/licenses. Voice weights and binary runtimes are not redistributed. FFmpeg, Python, NumPy/Pillow and librsvg/Cairo are existing local tools; no binary redistribution is included.

Lemo-Opuscar README, DIRECTOR.md and TECHNIQUE.md were inspected at https://github.com/lemomo-ai/lemo-opuscar. Its deterministic render(t), one timeline for picture/sound, world-to-screen, performance and review methods inform this architecture. No Lemo demo code, film, still, music or voice was copied; no Lemo renderer was installed or claimed. Its own full runtime has additional dependency/version requirements, so the existing compatible pipeline is retained.

Whisper: the existing Transformers implementation imports successfully; one free tiny.en weight download was attempted and blocked by the proxy with “Tunnel connection failed: 403 Forbidden”. No retry or new package install was made. Known generated narration uses real phrase lengths. ElevenLabs: no authorized zero-cost entitlement/credential is available; no paid API was called. Existing HeyGen tools mentioning voice engines do not establish free service authorization. Blender/Remotion and redundant frameworks are unnecessary for this illustrated pipeline. No clone retry or new dependency installation was performed. One free model-weight request was blocked, as recorded; no new model was installed.
