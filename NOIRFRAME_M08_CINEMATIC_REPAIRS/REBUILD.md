# Free local rebuild/editing

Dependencies used: Blender4.3.2, Python3.12, NumPy/SciPy/Pillow/CairoSVG, FFmpeg/ffprobe, g++17. Optional Chromium/Playwright for playback QA. No paid keys/services.

Compile `g++ -O3 -shared -fPIC -std=c++17 source/fast_raster.cpp -o source/fast_raster.so`.

`actions_M08.py`, `actions_M08F.py` (curtain), or `actions_M08J.py` + `run_repair.py` (running) + shared legacy controllers/vehicle_system → actual inherited native M04 armature → native leg/arm/digit IK → `.blend` and evaluated mesh cache → `render_clips.py` with cameras/sets/illustrated head → FFmpeg → `sound_finish.py`.

Official versions are listed in reports/SHOT_REVISIONS.json. The M08F curtain bake includes the corrected material-width solver and camera on the gripping-hand side. M08/M08B/M08C/M08D/M08E working curtain files are internal history, not final selections.

To edit native actor animation, save as a NEW model and run (example):

```sh
blender -b blender/MY_EDIT.blend --python source/evaluate_saved.py -- --shot KEY_LOCK --tag EDIT --controller source/actions_M08.py
python source/render_clips.py --shot KEY_LOCK --tag EDIT --width 1080
```

`evaluate_saved.py` exports actual edited native bones/meshes. It does not rebuild poses. Do not add `--final` for an experiment: that switches to the official revision map. All outputs refuse existing filenames. Native actor caches are omitted from the source package but regenerated by this utility. The native staircase evaluated cache is included with its editable `.blend` because it uses the preserved M05 schema. `polish_stairs_m08.py` opens the included M05 baseline, edits torso/arm controls only and invokes `export_stairs_m08.py`.

For controller edits, work in a fresh copy, edit the matching controller, copy it to `actions.py`, and use `blender -b --python source/bake_native.py -- --shot KEY_LOCK --tag NEW`. Then render the new tag. The builder retains bound M04 meshes, no-stretch native legs and adds native two-bone arm and digit IK. Coordinates are metres, sourceY-up → BlenderZ-up by B(x,y,z)=(z,x,y).

Props/world/cloth/vehicle timing is authored in actions.py, source/legacy/, sets.py, vehicle_system.py. Rebuild native mirrors after controller edits. Native prop-only GUI changes are not consumed by the scripted prop renderer. Cameras use cameras.py with historical snapshots retained for native-producer hashes. Actual driver-local/world clipping is in render_clips.py. Facial illustration uses approved_head_view.py and view_head.py.

Run validate_interactions.py, validate_props.py, check_door_body.py, validate_exit_terrain.py, check_inherited_stairs.py, validate_world.py, native_reopen_check.py and check_native_props.py for their stated measured scopes. `review_playback.py` records actual displayed video frames at requested speed; it does not grant subjective approval.

Source package contains editable final native scenes, controllers, C++ source, selected reports and inherited staircase cache. Runtime render intermediates use/tmp due workspace disk limits. Published download files are ordinary repository blobs, not links to/tmp.

Do not touch M07/V10 or assemble the full film without a new instruction.
