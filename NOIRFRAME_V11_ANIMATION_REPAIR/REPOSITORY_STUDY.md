## ClaudeAnimationBase

Studied JohnHeibel/ClaudeAnimationBase README, ANIMATION_GUIDE.md and MIT license through the connected GitHub reader. Applied: readable key poses, cause→contact→reaction, anticipation, differently delayed body/head/arms, avoiding paired mirrored limbs, giving the viewer time for each read, first/mid/last views and dense contact crops. Did not copy Clawd or its story, brush style, no-text rule or default scene. NOIRFRAME's approved head/cap/hoodie, navy/teal/amber palette and cinematic inserts remain. The implementation uses independently authored SI rigs plus the project's existing vector drawing infrastructure, not the kit's character source.

Reference: https://github.com/JohnHeibel/ClaudeAnimationBase

## Onetake

Studied feitangyuan/onetake README, SKILL.md and PolyForm Noncommercial1.0.0 license. General continuity concepts used: keep the same prop, world coordinates and screen direction across a beat; make the cause of movement visible; let the action carry a motivated cut; keep event-derived sound. No Onetake library, template or restricted source code is copied into this project. Its literal one-take/promo style and new-look defaults do not override this film's approved designs.

Reference: https://github.com/feitangyuan/onetake

## VOX-COLLAGE-BROLL

Studied MegaTroll222/VOX-COLLAGE-BROLL README, SKILL.md and MIT license. Useful optional editorial idea: inspect the actual opening, intermediate action and final pose independently, and preserve failed versions. Its MaxFusion/Gemini/ElevenLabs generation pipeline and photographic halftone collage treatment are not used. No paid account, key or generation request is required or invoked. The skill's separate metaphor/still approval flow is not applied to this character repair task.

Reference: https://github.com/MegaTroll222/VOX-COLLAGE-BROLL

Research copies stay outside the production folder. No third-party library installation or Git clone was needed. This study is not a claim that installing a toolkit improves animation; the changed source actually rebuilds the action and constraints.
