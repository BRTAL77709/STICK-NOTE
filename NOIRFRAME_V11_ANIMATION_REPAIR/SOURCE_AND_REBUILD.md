# Editable source and local reproduction

The new previews are generated by source/actions.py (timing/world targets), rig.py (skeleton/IK/stance), scenes.py (one door asset, stairs, upper window/cloth/car and cameras), drawing.py (shared illustrated character/materials), approved_head.py (existing approved witness head), svg.py (local SVG/Cairo raster) and render.py (streaming encoding and contact Foley). World axes are X across the room, Y up and Z into the house, in metres. No old clip is an animation input.

Requirements: Python3, NumPy, Pillow, FFmpeg with libx264/AAC, and local librsvg/Cairo/GObject. Chromium/Playwright are needed only for playback review. These are the existing free local tools; no GPU, API key, voice service or model download is required.

Rebuild in a new empty directory, preserving all delivered files:

`python source/rebuild.py --out /absolute/path/to/a/new/directory`

The wrapper copies current source only, creates fresh assets/output folders, renders three1080 clips and runs contact checks. It does not copy the rejected film or pose images. Fresh outputs are never written over an existing directory. Foley caches are fixed for a shot's current event plan; use a fresh rebuild folder after changing contact timing so old audio cannot be reused silently.

To make an additional same-timing render in an existing project, use render.py with --shot HOUSE, --width 1080 and a new --version label. Never use an existing output name. --wide disables House mechanism inserts, retaining the same world performance. Dense world-state JSONs record every evaluated frame; the source hashes used by the selected renders are included. Key SVG files are editable in ordinary vector tools, and all joint/prop geometry can be changed in source.

source/qa.py checks bone lengths, planted soles, rendered shoe vertices against tread levels, fingertip/prop constraints, rail contact and arm-centreline intersections with the door leaf. It is not an exhaustive garment-volume collision simulation or an artistic approval. source/review_playback.py plays the actual MP4s normally and slowly. source/export_review.py builds the encoded before/after videos and contact strips; reproducing comparisons additionally needs the preserved sibling NOIRFRAME_FULL_FILM_V1 movie.

No third-party restricted animation code is bundled. The user-owned approved head and existing SVG/raster infrastructure are reused; the three new performances are independently authored. REPOSITORY_STUDY.md explains which principles from the requested repositories were applied and why the noncommercial/paid-generation paths were not used.
