# Reuse for future NOIRFRAME stories

1. Create a fresh story directory. Copy source/config/fonts/GSAP and narration inputs, excluding `.venv`, `node_modules`, `.models`, `.hyperframes`, generated frame bundles/state, render outputs/reviews/reports and cached audio. Install/relink runtimes as in SETUP.md. Preserve the previous story directory.
2. Inspect approved assets and record reference provenance. Set one `shared/timeline.json` in integer frames. Specify actual blocking/actions/contacts before adding graphics. Write the narration script and use real approved speech audio.
3. Adapt the evaluators in `animation/`. Character rigs use target constraints/IK, independent planted feet and actual head silhouettes. Vehicle rigs use metric world motion, odometry and camera projection. House, keys/door, stairs, curtain/phone and trunk systems are available as copied source adapters; each needs narrative timing and action-specific QA. The demonstration exporter currently selects A/B; extend the dispatch/shot adapters deliberately for a new story.
4. Run `export_shared.py` on fresh generated inputs. It evaluates every SVG frame and exports the same vehicle/joint state to both renderers. It does not animate an arbitrary new story automatically. Preparation seals source/state/audio hashes in PREPARED_INPUTS.json; the rerender pipeline refuses stale prepared data. Keep a hash snapshot of your approved source/assets and a matching prepared-state hash for each production job.
5. Use Remotion for the full scene timeline. Use HyperFrames only for graphic regions; derive their local time from the master frame offset. Validate numerical HUD readings against the real state. Do not cover incomplete acting.
6. Once an actual local Whisper model is available, transcribe the actual narration with `transcribe.py`, inspect script differences and subtitle boundaries, and add forced alignment if verified word timing is required. Never relabel script captions as ASR. Current seven-second demo uses the documented script reference because the checkpoint is blocked.
7. Preview, inspect contacts and execute normal/slow playback. Render to a new job name with pipeline.sh. FFmpeg handles alpha composition, speech/cue mixing and H.264/AAC finishing. Extend the demo validators for the new storyboard's dimensions/duration/actions rather than assuming their seven-second assertions apply to a new film.
8. Check source/encoded frame correspondence, no blanks/unexpected repeats, camera/contact continuity, HUD timing and audio waveform alignment. Listen to narration/mix separately. Technical success does not establish artistic approval; submit the real MP4 for review.

The supplied pipeline.sh is a safe rerender of the prepared seven-second integration project into a new job directory. A new narrative requires new prepared state and adapted QC, not just changing a title or adding a motion-graphics panel.
