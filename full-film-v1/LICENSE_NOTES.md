# Assets, tools and license notes

The film's vector reconstruction uses the user-approved THE PRICE OF SILENCE sheets and authorized hidden-part approximation. The existing V10 character/trunk rigs are retained. New witness, street, house, room, phone and driving artwork is procedural source, not stock footage. The supplied reference MP4 guides visual/motion direction; no reference video frames, soundtrack or third-party footage are inserted in this film. User ownership/rights in supplied references are not independently adjudicated here.

All script text, procedural sound design and tonal suspense score were created locally for this project. No commercial stock music, paid voice service or paid API was used. Existing free FFmpeg Flite RMS/AWB voices synthesize the narrator/caller. The installed notices are reproduced in assets/audio/FLITE_COPYRIGHT_AND_LICENSES.txt; retain applicable notices when redistributing source/assets. No Flite voice database or binary is redistributed. See audio/AUDIO_LICENSE_NOTES.md for delivered editable assets and synthetic-performance limitations.

Python, NumPy, Pillow, librsvg/Cairo/GObject, FFmpeg/libx264, Playwright/Chromium and DejaVu Sans are runtime tools. Their binaries and font files are not bundled. DejaVu Sans is rendered into frames through the system font installation. Reusers must obtain their own compatible runtime installations and comply with their licenses. This document does not relicense the user project or third-party runtime software.

Budget: zero paid APIs/services; all rendering, speech and sound synthesis use tools already present in the execution environment.
